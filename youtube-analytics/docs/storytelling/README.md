## How to use these

Start with the current five-act reference, then review the self-video retrospective to see how the format behaves against real creator footage and performance data. Use the Coorg playbook as a working layer, not a fixed script: choose the primary story engine from the actual captured material, find the first tangible delivery of the hook, avoid duplicate VO/OC information, and close the story once. Fact-check history, culture, prices, routes and translations; preserve recorded on-camera dialogue verbatim. Transcript and performance reviews are evidence-led, but do not claim causal retention explanations when a retention curve is unavailable.

The application now has a v2.3-informed AI story-audit workflow and uses full-episode context during VO rewriting. AI output remains advisory: it must be compared with actual footage, and the creator explicitly applies rewrites. Use the [AI Storytelling Workflow](ai-storytelling-workflow.md) as the operating guide.
