# VlogScript Studio

A responsive, browser-local scene-by-scene vlogging script planner.

## Features
- Multiple projects and editable project metadata
- Scene headings, subheadings, purpose, location, duration, and director notes
- Separate voice-over and on-camera script areas
- Customisable shot checklist with camera angles, 4K/30, 4K/60, 4K/100 FPS, orientation, and completion status
- Progress indicators, scene duplication/reordering, and shot completion
- Browser-local persistence, JSON export/import, and print-friendly plans
- Responsive desktop and mobile interface

## Privacy
Projects are stored in this browser's localStorage. They are not sent to GitHub or any server by the app. Browser storage is specific to this browser profile/device. Export backups regularly; clearing browser data can remove projects.

## GitHub Pages
The deployment workflow runs from the `dev` branch. If Pages has not been enabled for this repository, open Settings → Pages, choose GitHub Actions, and rerun the workflow under Actions.
